# Internet of Things Challenges

Reports and code for the challenges and homework of the Internet of Things course: power consumption on a simulated sensor node, CoAP and MQTT traffic analysis, and a Node-RED data pipeline.

| | |
|---|---|
| Course | Internet of Things |
| University | Politecnico di Milano, M.Sc. Computer Science and Engineering |
| Semester | Spring 2024 |
| Type | Team challenges |

## Challenges

| Folder | Topic | Work |
|---|---|---|
| [`Challenge1/`](Challenge1/) | Wokwi and power consumption | Arduino sketch of a sensor node simulated in Wokwi, with an energy analysis |
| [`Challenge2/`](Challenge2/) | CoAP and MQTT traffic analysis | Python scripts that answer questions about a captured network trace |
| [`Challenge3/`](Challenge3/) | Node-RED | Node-RED flow that filters MQTT messages, logs acknowledgements and plots the data |
| [`Homework/`](Homework/) | Course homework | Written homework solutions |

Each challenge folder contains the assignment (PDF), the LaTeX source of the report, and the submitted files.

## Tech stack

Arduino and Wokwi, Python, Wireshark captures, MQTT, CoAP, Node-RED, LaTeX.
